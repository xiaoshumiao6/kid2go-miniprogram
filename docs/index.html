GitHub 图片访问测试

仅测试5张历史实景小图的访问，不是小程序正式版，也不代表景区当前状态。请先关闭代理，再分别在 Wi-Fi 和移动网络下测试。

图片为来源站提供的约500px缩略图，单张约38–75KiB。本次不裁切、不调色；结果不代表最终封面规格的性能。网页访问通过，也仍需另做小程序真机验收。
“加载”重复使用相同地址，可能命中缓存；换查询参数也不保证清空浏览器或服务器缓存。单图超时20秒。耗时从设置地址计至 load/error 事件，不是纯网络TTFB。
